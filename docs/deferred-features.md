# Deferred features

At the cut-over (Phase 8) quarry stopped depending on the upstream backend, and Phases 5 (automations), 6 (platform) and
7 (integrations) were skipped for now. Their screens were removed from the frontend rather than left calling an API that
no longer exists. Billing, budgets, licensing and the cloud trial were dropped as product decisions and will not come
back.

To bring an area back: port its backend into `apps/api` (PLAN.md §9 lists the module for each phase), then copy the
frontend files listed below from `../fork-reference/apps/frontend/src/` — every removed file still exists there at the
same path — and point them at the new GraphQL fields through a `lib/*-api.ts` module, as the ported areas do
(`lib/apollo-procedures.ts`, types in `lib/api-types.ts`). Restore the nav entries (`components/sidebar-settings-nav.tsx`)
and search entries (`components/settings-search-index.ts`) from upstream at the same time.

Upstream backend paths below are relative to `../fork-reference/apps/backend/src/`, frontend paths to
`../fork-reference/apps/frontend/src/`.
